# Icon Placeholder

The application is configured to use an icon file at `build/icon.ico`.

To add a custom icon:
1. Create or obtain a 256x256 PNG image with your desired icon design (e.g., Star of David)
2. Convert it to .ico format using an online converter like:
   - https://convertico.com
   - https://png2ico.com
   - https://cloudconvert.com/png-to-ico
3. Save the .ico file as `build/icon.ico`

For now, the application will build without an icon, or you can use Windows default icon.
